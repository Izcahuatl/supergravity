Supergravity

An agentic coding desktop app in the spirit of Google Antigravity - but not locked to one vendor's models.

Any model you want

OpenAI, Anthropic, Gemini, local Ollama models, or any OpenAI-compatible endpoint. Mix and switch per conversation - no vendor lock-in.

A real agent

Reads, writes, and edits files, searches code, and runs shell commands - with per-type approval policies so you decide what runs free and what asks first.

Workshop

Every conversation gets its own scratch sandbox for python scripts and experiments, with full permissions - your project stays clean.

Rewind & checkpoints

Every file change is checkpointed. Rewind a whole turn or revert a single file - undo is never a leap of faith.

The details

Task-plan checklists, @file mentions with context attached, diff previews on every approval, Windows toast notifications when a run finishes.

Built with

Rust + Tauri on the inside, a hand-rolled vanilla JS UI on the outside. No electron bloat, no telemetry - it runs where your code lives.
